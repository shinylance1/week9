# RAGFlow + FastGPT 数字客户智能体方案

本目录提供一套可在内网部署的「数字客户智能体」参考实现方案，面向客户经理的风险营销建议场景：客户经理输入客户号或客户名称后，系统通过客户数据 API 获取行业、业务数据、量化画像、司法数据、征信数据，再结合 RAGFlow 中的行业策略、风控政策、营销产品规则和合规话术，由 FastGPT 编排生成带引用的风险营销建议。

## 推荐职责划分

| 组件 | 职责 |
| --- | --- |
| FastGPT | 客户经理交互入口、流程编排、HTTP 调用、最终答案生成、引用展示 |
| RAGFlow | 复杂文档解析、知识库管理、行业/风控/营销/合规知识检索、证据片段返回 |
| 适配器服务 | 对接客户数据 API、RAGFlow 检索 API，统一返回结构化上下文和引用元数据 |
| 客户数据 API | 返回客户行业、业务数据、量化画像、司法数据、征信数据、风险标签和营销标签 |
| 本地模型服务 | 提供 LLM、Embedding、Rerank 等模型能力，可用 vLLM、Ollama、Xinference 等 |

## 核心原则

1. 行业不由大模型识别，必须以客户数据 API 返回的 `industry_code`、`industry_name`、`industry_tags` 为准。
2. 风控营销建议必须基于客户 API 数据、RAGFlow 检索内容、风控政策和营销规则。
3. 关键结论必须带引用定位；没有依据时必须提示依据不足。
4. 大模型只做解释、归纳、建议和话术生成，不直接决定授信、准入、压降、退出等最终风控动作。
5. 输出应结构化，便于回写 CRM、审计留痕和后续效果评估。
