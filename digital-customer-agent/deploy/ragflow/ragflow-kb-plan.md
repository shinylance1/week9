# RAGFlow 知识库建设计划

## 1. 数据集建议

| 数据集 | 说明 | 示例文档 |
| --- | --- | --- |
| `industry_policy_dataset` | 行业策略和行业研究 | 纺织业授信策略、光伏行业经营分析、房地产行业风险提示 |
| `risk_policy_dataset` | 风控政策 | 授信准入规则、压降退出规则、对外担保管理办法 |
| `marketing_policy_dataset` | 营销产品和客群经营策略 | 供应链金融手册、票据池方案、结算经营指引 |
| `compliance_dataset` | 合规话术和禁止承诺 | 客户经理合规话术、金融营销宣传规范 |
| `case_dataset` | 历史案例 | 行业风险暴露案例、成功营销案例 |

## 2. 文档元数据

导入文档时建议维护以下元数据：

```json
{
  "industry_code": "C17",
  "industry_name": "纺织业",
  "business_line": "对公授信",
  "risk_level": "medium",
  "product_type": "供应链金融",
  "region": "浙江",
  "effective_date": "2026-01-01",
  "expire_date": "2026-12-31",
  "version": "V3.5",
  "approval_status": "approved"
}
```

## 3. 切片建议

- 政策类文档按条款切分，保留条款号；
- 行业报告按章节切分，保留页码和章节标题；
- 产品手册按产品准入、适用客群、风险控制、营销话术切分；
- 合规话术按禁止项、允许项、提示项切分；
- 每个 chunk 尽量保持完整语义，不要跨越多个政策条款。

## 4. 检索质量验证问题

每个行业至少准备 10 个验证问题，例如：

```text
纺织业客户存在对外担保偏高时应如何控制风险？
光伏材料客户短贷增长较快是否可以新增信用敞口？
房地产客户司法涉诉较多时可以营销哪些低风险产品？
钢贸客户存货真实性不足时应重点核查什么？
餐饮客户流水稳定但租赁期限短，适合推荐什么产品？
```

## 5. 引用质量要求

- 每条风险建议应能定位到文档、章节、页码或条款；
- 引用片段必须与结论直接相关；
- 不允许用营销产品文档支撑风控准入结论；
- 不允许用行业一般性描述支撑具体授信额度建议；
- 无引用时必须返回依据不足。
